# 7ninnnosamurai

Unityで制作した「七人の侍」モチーフの試作プロジェクトです。

## 概要

Unity HDRPテンプレートをベースにした実験/学習用プロジェクトです。シーン、設定、プリセット類を含みます。

## 主なディレクトリ

- `7samurai/Assets/Scenes/` - Unityシーン
- `7samurai/Assets/Scripts/` - スクリプト
- `7samurai/Assets/Settings/` - HDRP/Unity設定
- `7samurai/Assets/Presets/` - 各種プリセット

## 開き方

1. Unity Hubで `7samurai/` ディレクトリを指定して追加
2. Unityでプロジェクトを開く
3. `Assets/Scenes/` 以下のシーンを開いて再生

Unityバージョンは `7samurai/ProjectSettings/ProjectVersion.txt` を確認してください。

## メモ

初期のUnity試作プロジェクトのため、実装や構成は実験段階のものを含みます。
